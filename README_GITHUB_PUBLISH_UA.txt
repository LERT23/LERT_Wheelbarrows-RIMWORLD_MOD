LERT WHEELBARROWS — ЗАВАНТАЖЕННЯ ВИХІДНОГО КОДУ НА GITHUB
=======================================================

Репозиторій:
https://github.com/LERT23/LERT_Wheelbarrows-RIMWORLD_MOD

ШВИДКИЙ ЗАПУСК
1. Розпакуй ВЕСЬ ZIP в окрему звичайну папку.
2. Запусти Upload_Wheelbarrows_to_GitHub.bat подвійним натисканням.
3. Під час першого запуску потрібен інтернет. Інструмент прочитає наявну
   історію репозиторію, збереже його LICENSE та під’єднає цю папку до GitHub.
4. У графічному вікні переглянь ЗМІНЕНІ ФАЙЛИ й натисни ЗАВАНТАЖИТИ.
5. Якщо GitHub попросить авторизацію — увійди через звичайний Git Credential
   Manager/браузер. Дочекайся SUCCESS. ВІДКРИТИ GITHUB відкриває репозиторій.

Не запускай BAT без решти файлів ZIP. Не запускай ZIP як папку.
Git for Windows має бути встановлений і доступний як git.exe.
На цьому комп’ютері Git уже знайдено. .NET SDK для завантаження не потрібний.

ЩО ПІДГОТОВЛЕНО
Це самодостатня копія вихідного коду та ресурсів мода 0.3.0:
Source, Tests, About, Defs, Languages, Patches, Textures, Assemblies та build.ps1.
У Assemblies міститься лише власна DLL мода. Бібліотеки RimWorld/Harmony
не постачаються. Ігрові збереження, сторонні проєкти, папки bin/obj,
службові логи та приватні ключі не входять до початкового комплекту.

КНОПКИ, ЯК У ТВОЄМУ GitHubBackupTool
ЗАВАНТАЖИТИ — git add -A, коміт із датою, потім push у поточний upstream.
ОНОВИТИ СТАН — стан файлів, гілки та доступності віддаленого репозиторію.
ВІДКРИТИ GITHUB — сторінка цього репозиторію.
ІСТОРІЯ — останні 30 комітів, без редагування.
Живий журнал показує виконання команд і повідомлення Git.

Якщо є готові локальні коміти без нових змін, ЗАВАНТАЖИТИ повторює лише push.
Якщо все синхронізовано, порожній коміт не створюється.
Якщо push не вдався, локальний коміт залишається для наступної спроби.

ВАЖЛИВО ПРО РОБОЧУ ПАПКУ
Після першого запуску саме розпакована папка стає локальним Git-репозиторієм.
Подальші зміни для GitHub роби в її Source та ресурсах і запускай цей BAT.
Інструмент НЕ читає автоматично свіжі файли з папки встановленої гри
або з оригінальної робочої папки Codex. Для майбутніх оновлень перенеси
нові вихідні файли й ресурси в цю папку перед завантаженням.
Початкове під’єднання не замінює твій GitHubBackupTool для Age of Lert.

ЗБЕРЕЖЕННЯ ІСТОРІЇ
Перше під’єднання завантажує віддалену гілку у службовий каталог, переносить
Git-метадані до папки мода й додає відсутні віддалені файли. Поточні вихідні
файли мода не переписуються. Ліцензія з GitHub зберігається; README мода
стане звичайною зміною поверх початкового README репозиторію.
Ні clone, ні відкриття GUI самі по собі не завантажують код на GitHub.
Коміт і push починаються після натискання ЗАВАНТАЖИТИ.

Інструмент не робить push --force, pull, reset, rebase або автоматичне
розв’язання конфліктів. Віддалене випередження/розходження, конфлікти,
detached HEAD чи незавершені Git-операції блокують завантаження.
У такому разі журнал пояснить причину; інтеграцію гілок виконай окремо.
Існуючі ім’я/email Git зберігаються. Якщо їх немає, налаштовується лише
для цієї папки LERT23 та GitHub noreply-адреса цього облікового запису.
Паролі й токени інструмент у свої конфігураційні файли не записує.

ПОМИЛКИ ЗАПУСКУ
Залишиться повідомлення в BAT-вікні; подробиці також зберігаються в
tools\GitHubBackupTool\startup_error.log.
Службовий каталог .runtime та цей лог виключені через .gitignore.

ПІДГОТОВКА ЦЬОГО КОМПЛЕКТУ
Завантаження/коміту/push під час створення комплекту не виконувалося.
Вихідний інструмент Age of Lert і встановлений мод не змінювалися.

Перед формуванням коміту та безпосередньо перед push перевіряються всі фактичні
push-адреси поточного upstream. Інший репозиторій блокується без зміни Git-конфігурації.
Друге одночасне вікно для цієї папки блокується локальним файловим блокуванням.
