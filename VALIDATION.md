# Lert's Wheelbarrows 0.3.0

Оновлення інтегровано в установлену папку C:\GAMES\RimWorld\Mods\LertWheelbarrows.

Зміни:
- Категорія «Тачки» у вироблених предметах, торгові теги Wheelbarrow / WorkTransport / HaulingEquipment та матеріальні теги.
- Нові запаси відповідних торговців: дерев’яні/сталеві у побутових, пласталеві в екзотичних; тачки також у відповідних поселеннях. Запаси випадкові, формуються для нових торгових асортиментів.
- Необов’язкова сумісність з Allow Tool «Срочний перенос»: пішка з увімкненим користуванням тачками спочатку бере доступну придатну тачку, навіть для одного стосу. Добір у цьому рейсі обмежений позначеними терміновими речами з доступним сховищем. Без тачки лишається нативне перенесення Allow Tool.
- Коректні назви повернення для трьох матеріалів українською, англійською та російською, без дублювання назви предмета. Нативні дії й пояснення недоступності збережено.
- Порожній/заповнений вигляд: будь-яка наявна одиниця вантажу вмикає заповнений варіант. Застосовується для верхнього та бічного вигляду, під час руху й на землі.
- Користувацькі зміщення бічних текстур збережено; активна тачка малюється над шаром пішки.
- Базова ринкова вартість: дерев’яна100, сталева250, пласталева820 срібла. Фактична ціна торгівлі залежить від нативних модифікаторів.
- Власні іконки дозволених матеріалів та розчищення рослинності на панелі паркування.
- Нативна іконка мода About/ModIcon.png з наданого зображення, включно з меню вимкнених модів.
- При виборі кількох тачок — «Повернути всі тачки». Заявки зберігаються; доступні перевізники з призначеною роботою перенесення повертають тачки незалежно від особистого перемикача автоматизації. Активним користувачам надсилається завершення рейсу. Потрібні доступні дозволені місця паркування. Тачки не телепортуються.

Графічні файли скопійовано з авторських папок Desktop/33 без перетворення, зміни палітри, роздільності, прозорості чи розміщення. У моді використано 12 зображень порожніх/завантажених тачок, 5 іконок команд і надану іконку мода. Редагування авторських вихідних файлів не виконувалося.

За вказівкою користувача тестів не створювали й не запускали, гру та ігровий тестовий стенд не запускали. Виконано лише статичний огляд коду та компіляцію Release проти встановленої RimWorld1.6: 0 попереджень, 0 помилок. Виправлено зауваження огляду щодо додаткових термінових речей без сховища; нативні перевірки маси, дозволеної області, шляху, резервувань і сховищ збережено. Роботу нових функцій у грі цим не підтверджено.

Оригінальні збереження та налаштування гри не змінювалися. Попередній мод збережений окремим резервним ZIP. Багатомовний опис About.xml з українським блоком першим збережено. Для підхоплення DLL та текстур потрібен новий запуск гри.
