# Texture provenance — 0.3.0

All current raster assets were supplied, edited, positioned and optimized into indexed PNG colors by LERT. They were copied without image processing, resizing, color conversion, palette changes or alpha changes.

- Things/LertWheelbarrows: six empty top/side sprites.
- Things/LertWheelbarrowsfull: six matching loaded top/side sprites, with the _full suffix.
- UI/keys: five command icons for allowed materials, vegetation and group parking.
- UI/lert_wheelscart_ico.png: author-provided mod icon. The identical file is copied to About/ModIcon.png for native mod-menu loading even while the mod is disabled.

The original empty sprites were generated earlier and subsequently modified by the author. The current asset authority is the author's supplied optimized files. The renderer rotates top views for north/south and mirrors side views for east/west. It does not alter the source PNGs. Loaded graphics represent any nonempty cargo, not a percentage fill level.
